## Estructura del Proyecto

```text
pearlhost-dashboard/
├── index.html       # Estructura principal y plantillas de vistas SPA
├── styles.css       # Sistema de estilos, variables CSS y diseño adaptativo (Desktop / Mobile)
├── script.js        # Lógica de negocio, modales, control de estados y modo oscuro/claro
└── README.md        # Instrucciones de instalación y despliegue
```

## Requisitos Previos

Para ejecutar y probar este proyecto de manera local, solo necesitas un navegador web moderno:
- Google Chrome, Mozilla Firefox, Microsoft Edge o Safari (versiones recientes).
- Opcional: Un servidor local ligero como **Live Server** en Visual Studio Code para habilitar recarga en caliente.

## Instrucciones de Instalación y Despliegue Local

1. **Clonar o descargar** el repositorio en tu computadora:
   ```bash
   git clone https://github.com/tu-usuario/pearlhost-dashboard.git
   ```
   *(O bien, descomprime el archivo ZIP con los archivos del proyecto en una carpeta local).*

2. **Abrir el proyecto** en tu editor de código preferido (por ejemplo, **Visual Studio Code**):
   ```bash
   code pearlhost-dashboard
   ```

3. **Ejecutar la aplicación**:
   - **Método Directo:** Haz doble clic sobre el archivo `index.html` para abrirlo directamente en tu navegador web predeterminado.
   - **Método con Live Server (Recomendado):** 
     - Instala la extensión *Live Server* en Visual Studio Code.
     - Haz clic derecho sobre `index.html` y selecciona **"Open with Live Server"**. El proyecto se abrirá automáticamente en `http://localhost:5500`.
